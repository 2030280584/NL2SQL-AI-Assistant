# NL2SQL 智能数据分析助手 (基于 Coze/LLM)

## 📌 项目背景
在传统数据分析流程中，业务人员取数高度依赖技术团队写 SQL，沟通成本高。本项目基于 Coze 平台与大语言模型（LLM），搭建了一套自动化工作流，实现将自然语言（Human Language）直接转换为标准 SQL 语句（NL2SQL）。

## 🛠️ 技术架构
1. **输入节点**：接收用户的自然语言查询需求。
2. **大语言模型节点**：配置系统提示词（Prompt），注入数据库表结构（Schema），约束模型输出标准 SQL 语法。
3. **代码处理节点**：使用 Python 进行 SQL 语句清洗（去除 Markdown 格式、规范换行），确保输出结果可直接在数据库中执行。
